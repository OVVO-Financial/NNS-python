Decisions that need the author

These are design questions about the method itself. They are written up with evidence and options in R_PROPOSALS.md, and nothing was changed for them.

  • DEP-02 NNS.caus(tau = k) does not lag anything
    Option 1 now, with option 2 behind an argument (`prewhiten = FALSE`).
  • DEP-03 NNS.caus depends on location and scale (NNS.norm)
    Option 1, invariant to any monotone transform of either variable.
  • DEP-05 NNS.dep independence floor
    Option 4 now (documentation), then option 2, which keeps the 0..1 scale and needs no randomness.
  • DEP-12 signed "Correlation" = max(corr_xy, corr_yx)
    Option 2 for the symmetric measure. The max stays appropriate for the unsigned Dependence.
  • DEP-13 follow-up NNS.dep(p.value = TRUE) Correlation p-value
    Use the two-sided `(1 + sum(abs(null) >= abs(obs))) / (1 + B)`, and add `nperm` and `seed` arguments.
  • DEP-14 NNS.copula does not vanish under independence for skewed marginals
    Options 1 and 3.
  • TS-04 NNS.seas has no null calibration
    Option 1 plus option 4 now (cheap, deterministic); option 2 as an opt-in (`seas.test = "permutation"`).
  • SDA-10 ANOVA Certainty calibration
    Option 1, which is additive and keeps the current Certainty unchanged. Then decide option 2 separately.
  • extra NNS.stack Method 1, univariate design: the n.best candidates are not what is deployed
    Option 1, which keeps the deployed model.
  • extra dy.d_ (follow-up to REG-04): bandwidth attenuation
    Drop the 10x bands (or choose h like `dy.dx` does) and evaluate f(x ± h e_j) holding the other coordinates at the point. Use `order = "max"` / `n.best = 1` only for interpolation checks.
  • extra NNS.ARMA.optim reports the weights = NULL objective when equal weights are chosen
  • PM-08 NNS.mode(multi = TRUE) reports spurious modes that multiply with n
    Option 2 with a factor of 2 (about a 2-sigma bump), documented in the Rd, plus a `min.prominence` argument.
  • TS-25 NNS.meboot(drift = FALSE) rescales the replicates to the full sd(x), trend included
    Option 1, plus a sentence in the `drift` parameter documentation.
  • extra CORE-09 follow-up: exact tie tests against floating-point cell means
    Snap `|dx| <= 8 eps max|x|` to 0 in `copula_signed` (the fix proposed in DEP-09) and use a long-double (or pairwise) cell mean.
  • extra DEP-14 (remaining part, after CORE-09/CORE-10)
